Solutions are grouped by algorithmic topic. Each file contains the solution, local test cases in `main()`, and notes on time/space complexity.

## 🛠️ Local Environment & Testing

All compiled binaries (`.exe`, `.out`, `.class`) are ignored via `.gitignore` to keep the repository clean.

**To run a C solution locally:**

```bash
gcc 0001-two-sum.c -o solution
./solution

```

**To run a Java solution locally:**

```bash
javac 0242-valid-anagram.java
java ValidAnagram

```
